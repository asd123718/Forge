# Licensing

Forge is not a single-license tree.

- **Forge product overlay** (bridge, Live Edit, scripts, docs, branding) is
  intended to be Apache-2.0 when a root `LICENSE` file is present.
- **Code-OSS workbench** remains MIT. See `LICENSE.txt` (Microsoft copyright).
- **Codex** remains Apache-2.0. See `codex/LICENSE` and `codex/NOTICE`.
- Third-party notices for bundled components are in `ThirdPartyNotices.txt`.

The in-product license URL points at this repository, not microsoft/vscode.
It does not claim that every file in the tree is MIT.
